# AegisOS - Personalizable AI Companion Framework

A local-first, privacy-centric framework for creating your own AI companions.

## Quick Start
1. Run `python persona_builder.py` to set up your companion
2. Edit `config/persona.yaml` to customize personality
3. Run `python test_persona.py` to verify setup

## Features
- Name your companion anything you want
- Define custom personality traits
- Local-first, no internet required
- Modular architecture for easy expansion
